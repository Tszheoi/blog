TszTool for Android 更新日志

8.0.0 → 10.0.1 · 2026-10-25 ~ 2026-10-27 · 作者 Tszheoi Law

包名 com.tszheoi.TszTool。全部版本使用同一张签名证书，可直接覆盖安装（8.8.8 更换包名除外）。版本规则为 X.Y.Z，versionCode 取三段数字拼接（例如 10.0.0 对应 1000）。

二、各版本更新内容
8.0.0 · 待办事项（最简版）
新增
待办事项：新建任务、勾选完成、删除、清空已完成、未完成计数
入口在 Tsz+ 主页标题下方的卡片（不占底部 Tab），点开整屏接管
数据存 todo_items（SharedPreferences + JSON），备份新增「待办事项」分区

8.8.8 · 改名 / 换包名 / 作者
变更
应用名 Tsz+ 改为 TszTool（桌面图标名、主页默认标题、底栏首项、导出图页脚同步）
包名 top.tszheoi.tsztool 改为 com.tszheoi.TszTool：单段 TszTool 被 Android manifest merger 拒绝，因包名必须包含「.」，故补 com.tszheoi. 前缀
换包名等于换了 App：旧版数据不继承，需先导出备份、卸载旧版、安装新版、再恢复
作者署名改为 Tszheoi Law：写入安装包元数据（tsz.author），并在设置页底部显示，其它页面不显示
导出目录由 下载/Tsz+ 改为 下载/TszTool；备份 JSON 的 app 字段同步改为 TszTool（导入端只读 data，跨端仍可互导）

8.8.9 · 原生安卓沉浸适配与壁纸权限兜底
修复
原生安卓上标题被状态栏压住、底部胶囊被手势条盖住、深色主题下系统栏图标看不见：内容区加状态栏内边距、底栏加导航栏内边距，状态栏与导航栏图标明暗改为跟随 App 内主题
换壁纸在「系统不弹权限框」的设备上不可用，新增三条路径：
① 弹窗内「去设置授权」直接跳应用权限页，并附操作指引
② 从 App 专属文件夹选图（Android/data/com.tszheoi.TszTool/files/Pictures/），完全不需要权限
③ 相册「分享到 TszTool」直接设为背景（新增 ACTION_SEND image/* 接收）
背景图解码改为按屏幕尺寸采样，避免大图 OOM

9.0.0 · 外壳对齐 HAP 9.x
变更
底部栏改为 5 项：TszTool / 记账 / 待办 / 账户管理 / 验证器；待办从主页卡片升级为 Tab
设置移出底栏：改为各主页面标题右侧的齿轮，点开为全屏覆盖层（左上 ‹ 或系统返回退出）
主页「设置」按钮删除，只保留「＋ 新增」
新增
离页自动上锁（对齐 HAP 7.3.4）：切到其它 Tab 或进入设置时，账户管理与验证器立即锁定
升级迁移：旧 tabOrder / tabHidden 中的 settings 自动剔除，todo 自动插到「记账」后面；5 个 Tab 均可隐藏，系统保证至少保留一个可见项

9.3.0 · 待办增强 / 番茄钟 / 零散补齐
原计划拆为 9.1.0、9.2.0、9.3.0 三批，一次性完成后合并发布。
待办增强
字段：备注、截止日、优先级（普通/重要/紧急）、分类、重复（每天/每周/每月）、子任务
视图：今天 / 全部 / 已完成；分组：已逾期 / 今天 / 明天 / 本周 / 以后 / 无日期
重复任务勾选完成后自动生成下一份（日期后推、子任务重置）
长按菜单：编辑 / 上移 / 下移 / 删除；分类管理：新增 / 改名 / 删除（删分类只把其中的待办转为「未分类」，不删数据）
番茄钟
入口：待办页底部整行卡片（今日番茄数 + 专注分钟）
专注页：圆环倒计时、开始 / 暂停 / 继续 / 放弃、短休 / 长休（每 4 轮长休）、自由专注或绑定待办
统计：今日番茄数/分钟、最近 7 天柱状图、最近 8 条记录；时长设置与 5/15/30 分钟快捷
存储 focus_records / focus_cfg，已并入备份；纯前台计时，不做后台服务与锁屏提醒
零散补齐
验证器分组：Chip 切换、新建、删除（组内条目转到「默认」）
汇率：币种搜索与星标收藏（常用前置）
记账：四维筛选（类型 / 分类 / 账户 / 支付方式）与一键清空
首页条目：长按菜单增加「上移 / 下移」
自定义 Logo：设置里选图，开屏页优先显示

10.0.0 · 全量英文化 + 自检修复
英文
新增 I18n.s(中文, English) 双语机制；新增与既有页面的用户可见文案全部双语：待办、番茄钟、验证器分组、记账筛选/汇率/统计/转账/周期账单、账户管理与扫码、设置全部分节、备份、选图弹窗、WebView 兜底页、首页菜单、CSV 表头与错误、环形图水印、转账备注、分享标题
修复「切英文只有当前页变」：新增 AppState.i18nVersion，语言切换后整棵树重组
有意不翻译：分类名、账户名、支付方式、默认分组、[周期] 标签、日期格式、币种代码（属数据值，翻译会修改数据或破坏逻辑比较）
自检修复（UI 与回归）
待办页小屏遮挡：番茄卡从固定底部移入列表末尾（两个视图都有，空态也可达），空提示去掉固定高度
首页长按菜单英文变宽后溢出：Browser / Move up / Move down / Delete 拆成两行
备份分区补 rate_fav（汇率收藏）与 auth_groups（验证器分组），避免「标称有分区、实际没备份」
验证器分组后排序会跨组交换（点了像没动）→ 改为同组内相邻交换
备份分区显示名双语；清理 settingsSub 死状态
CSV 表头与合计行、环形图导出文字、转账备注按当前语言输出

10.0.1 · 设置页恢复密码门
修复
9.0.0 把设置从底部 Tab 改成页头齿轮覆盖层时漏掉了管理员密码门：点齿轮直接进设置。现在恢复为与账户管理、验证器一致的解锁流程
进设置先要管理员密码（默认 Admin），已开启指纹/面容的可用生物识别解锁
关闭设置（左上 ‹ 或系统返回）立即重新上锁，再次进入需重新验证
初始密码未修改时，解锁页仍提示「初始密码：Admin」
设置内部的「修改管理密码」仍需二次验证，逻辑不变

三、升级注意
1.7.x / 6.x 升级到 8.8.8 及以后：包名已变，属于另一个 App。请先在旧版本「备份与恢复 → 导出到下载目录」，再卸载旧版、安装新版，最后从备份恢复。

2.8.8.8 升级到更高版本：直接覆盖安装，数据保留。

3.待办字段升级：8.0.0 的待办只有标题与完成状态，9.3.0 起缺失字段走默认值，不会崩溃。

4.旧备份可导入新版本：恢复只读取文件里的 data；新版本多出来的键在旧版本里会被忽略。

四、已知限制
数据仅存本机，卸载即丢失，请定期用「导出到下载目录」备份。
番茄钟不做后台常驻与锁屏准点提醒（需要前台服务与通知权限，另行评估）。
验证器只支持 TOTP（SHA-1），不支持 HOTP / SHA256 / SHA512。
自定义背景与 Logo 存放在沙箱路径，换设备需重新选择。
桌面图标名不可动态修改（Android 无官方 API），App 内主页名可改。
桌面卡片加入负一屏无法实现（各厂商私有入口）；真毛玻璃背景不建议做。
