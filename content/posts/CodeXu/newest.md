当前版本 9.1.4 全功能总览
本节按功能逐项介绍当前版本的全部能力，配图为 7.6.1 界面（折叠屏外屏 1:1）。外屏与内屏使用同一套功能，仅布局与背景不同。
1. Tsz+ 主页（功能入口）
![主页](/images/1792944387261-__.png)
7.6.1 外屏：主页 / 记账 / 统计 / 管理
条目网格：竖屏单列、横屏双列自动切换；每条显示名称与箭头，点击用系统浏览器打开。
标题与计数：自定义主页名与「共 N 项」同行显示（7.1.1 起）。
条目增删改：新增、编辑、删除、▲▼ 排序、清空；长按条目可直接编辑/删除。
打开网页：独立的 Web 页（带顶栏、进度条、页面内后退、加载失败重试）。
首次安装预置一条 DeepSeek；升级不清空已有条目。
2. 记账
![记账](/images/1792944404838-__.png)
记一笔：金额、支出/收入切换、分类、账户（币种）、支付方式、日期、备注；账户与支付方式均为横向 Chip，点选即填。
月度汇总：支出 / 收入 / 结余三项，随月份切换实时刷新。
总资产（7.4.0）：按汇率把全部账户折算成 CNY 汇总，下方列出各币种原币余额。
分类占比：Canvas 环形图（圆头扇形 + 扇区间隙），带百分比与金额图例；可「存图」导出 PNG 到沙箱。
预算：月度总预算 + 分类预算；存在分类预算时总预算按分类合计计算，进度条实时。
统计：本周 / 本月 / 本年切换；分类排行；分币种明细（每币种支出与收入）。
筛选：类型 / 分类 / 账户 / 支付方式四维叠加，清空一键复位。
转账：支持跨币种，出账与入账金额分开填写，可自动按汇率换算。
周期账单：设置每月几号 + 金额，进 App 自动补记本月（标签去重不重复入账）。
CSV 导出：带 BOM（Excel 直开不乱码），含合计行。
多币种账户：CNY 主账户置顶，副账户可按币种自动命名（CNY / CNY* / CNY**）并可排序。
3. 账户管理
![账户管理](/images/1792944418708-____.png)
7.6.1 外屏：账户管理 / 验证器（分组）/ 设置 / 个性化
进入需管理员密码，支持指纹 / 面容解锁；离开页面自动上锁（7.3.4）。
分类：订阅 / 电话号 / 银行卡 / 账号 四类预置，可自定义新增，长按分类可删除（连带该分类记录）。
记录字段：名称、账号/卡号、金额、到期日、备注；支持新增、编辑、▲▼ 排序、删除。
分类内记录按自定义顺序排列，切换分类保留各自顺序。
4. 验证器（TOTP）
![验证器](/images/1792944436103-___.png)
标准 TOTP（RFC 6238），已用官方测试向量校验（T=59s→94287082 等 6 组全部通过）。
密钥使用 HUKS 生成的 AES-256-GCM 密钥加密后存储（nonce + 密文 base64），不明文落盘。
添加方式：手动粘贴 otpauth:// 链接或 Base32 密钥；或调用系统扫码（ScanKit）识别二维码。
列表：6 位验证码 + 剩余秒数 + 周期进度条（剩余 ≤25% 变红），点击验证码复制到剪贴板。
分组（7.4.2）：顶部 Chip 行切换分组，＋ 新建分组，长按删除分组（组内条目移到「默认」，不删数据）；「默认」不可删。
导出：生成 otpauth:// 列表到剪贴板，便于迁移或跨设备。
进入需密码 / 生物识别，离开自动上锁。
5. 设置
![设置](/images/1792944446901-__.png)
主页名称：实时改名（桌面图标名不随之改变，属系统限制）。
个性化：logo 与 6 张背景图（外屏深/浅、横屏深/浅、竖屏深/浅）分别从相册选择或清除。
备份与恢复：分区选择、文件导入导出、剪贴板备份。
外观：主题跟随系统 / 浅色 / 深色。
语言：跟随系统 / 中文 / English（非中英环境回退中文）。
安全：修改管理密码（默认 Admin，提示「初始密码」直到被修改）。
解锁方式：指纹、面容分别开关。
底部栏：排序与隐藏；设置页固定不可隐藏；至少保留一个可见项。
条目管理：主页条目的集中增删改。
6. 备份与恢复
![备份与恢复](/images/1792944458131-_____.png)
7.6.1：备份与恢复 / 实时汇率 / 密码页 / 开屏页
分区：主页条目 / 记账数据 / 账户管理 / 验证器 / 设置项，可只备份其中几项。
文件方式（7.3.0）：系统文件选择器导出 .json 到任意目录；从文件导入按分区合并。
剪贴板方式：适合小数据量快速传输，仍保留。
合并语义：数组按 id / name 去重追加，设置类本地优先，绝不删除本地已有数据（6.1.0）。
跨平台：JSON 结构与安卓版一致，两端可互导；验证器密文受 HUKS 保护，跨设备请用「导出 otpauth」。
7. 汇率与多币种
![汇率与多币种](/images/1792944472920-______.png)
数据源 open.er-api.com，CNY 为基准；页面可一键刷新实时汇率。
任意两币种换算：输入金额 → 选「从 / 到」→ 即时显示结果与 1 单位外币折 CNY。
160+ 币种全量列表，支持搜索；点亮星标加入常用（记账账户可选）。
分币种明细二级页：CNY 主账户置顶，其他币种降级显示。
8. 外观、开屏与折叠屏适配
全屏背景：内置 6 张（外屏深/浅 1:1、横屏深/浅、竖屏深/浅），可逐张替换为相册图片；图片存沙箱路径。
玻璃底栏：backdropBlur(12) + 30% 透明 + 1px 高光边 + 阴影，5 个手绘线条图标统一 20px 高度。
开屏页：背景图全铺 + 自定义主页名呼吸动画 + 版本号（从包信息读取，不写死）。
折叠屏外屏（1:1）识别：宽高比差 < 14% 视为外屏，单独收紧顶部间距、缩小标题字号、压缩锁屏间距。
外屏锁屏可滚动：账户管理 / 验证器 / 设置三个密码页内容超出时可下滑，且都为悬浮底栏留出高度，按钮不被遮挡。
内屏（展开）布局与 7.3.x 完全一致，外屏优化不生效。
9. 安全与隐私
管理员密码门：账户管理、验证器、设置安全项均需密码。
生物识别：UserAuthenticationKit，单方式请求 + ATL3→ATL2 回退，失败给出错误码文案。
离页自动上锁：切换到别的 Tab 立即锁定，返回需重新验证。
验证器密钥：HUKS AES-256-GCM，密钥不可导出；HUKS 失败时有兜底路径，不会崩。
数据本地化：全部存本机 preferences，不联网上传（仅汇率查询访问公开 API）。
权限：INTERNET、ACCESS_BIOMETRIC、CAMERA（仅扫码用，含 reason/usedScene）。
10. 已知限制
数据仅存本机，卸载即丢失——请定期用「导出到文件」备份。
验证器仅支持 TOTP（SHA1），不支持 HOTP 与 SHA256/512。
背景图自定义存沙箱路径，换设备需重新选择。
桌面图标名不可动态修改（HarmonyOS 限制）；App 内主页名可改。
底层玻璃材质为半透明 + 模糊近似，非系统原生毛玻璃（已确认不做）。

六、说明
所有版本使用同一签名证书覆盖安装，本地数据保留。
1.0.0 与 1.0.1 大小相同：后者仅改配置未增资源。
3.2.0 为 4.0.0 构建副本，未单独发布。
7.6.0 因新增两张外屏背景，包体从 2302 KB 增至 2560 KB。
验证器算法与分组逻辑均已用自动化脚本回归（TOTP 31 项、分组 29 项）。
七、8.x 版本：待办、番茄钟与桌面卡片
8.0 起，TszTool 从一个「工具入口 + 账本」扩展成「入口 + 账本 + 待办执行」：底栏改为 5 项（Tsz+ / 记账 / 待办 / 账户管理 / 验证器），设置不再占底栏，改由每页右上角的齿轮进入。
1. 底栏重构与设置归位（8.0.0）
底栏 5 项：Tsz+、记账、待办、账户管理、验证器；设置从底栏移除，改为各页右上角「页头动作区」。
横屏与竖屏页头铺开显示全部动作，折叠外屏（1:1）收进「⋯」菜单，避免一行挤三个按钮。
设置页改为覆盖层：左上角‹或系统返回键退出；「条目管理」按要求留在设置内，仍在密码门之后。
升级安装自动迁移：静默剔除旧版 tabOrder / tabHidden 中的 settings，并把 todo 插入记账之后，无需手动操作。
「设置固定不可隐藏」的特判随之删除，5 个 Tab 均可隐藏，系统保证至少保留一个可见项。
2. 待办（8.0.0）
六种视图：今天 / 全部 / 已完成 / 按日期 / 日程 / 统计，顶部一行切换。
字段：标题、备注、截止日、优先级（普通/重要/紧急）、分类、重复（每天/每周/每月）、子任务。
子任务可逐项勾选，主列表直接显示完成进度。
截止日分组：已逾期 / 今天 / 明天 / 本周 / 以后 / 无日期。
重复任务勾选完成后自动生成下一份，日期后推、子任务重置，不重复堆积。
拖动排序：长按待办可上移 / 下移，顺序写入本地并持久化。
分类管理：新增 / 改名 / 删除；删除分类仅将其中待办转为「未分类」，不删数据。
3. 番茄钟（8.0.0）
入口在待办页底部整行卡片（列表下方、新建待办上方），左侧显示今日番茄数与专注分钟，右侧「开始专注」。
专注页：Canvas 圆环倒计时、任务名、开始 / 暂停 / 继续 / 放弃。
完成一个番茄：写入专注记录、该待办番茄数 +1、累计专注分钟 +N，并按轮次自动进入短休 / 长休。
时长可改，默认专注 5 分钟、短休 15 分钟、长休 30 分钟、每 4 轮长休；没有待办时也可「自由专注」。
统计页：今日番茄数、今日专注分钟、本周专注时长条形图（周一到周日）、最近 8 条专注记录。
4. 日程表（8.1.1）
课表式周视图：横排周一到周日，每列列出当天到期待办，今天日期高亮，紧急项红字。
左右箭头切换上一周 / 下一周，非本周时标题显示日期范围；点格子内待办可直接编辑。
5. 桌面服务卡片（8.1.0 – 8.3.0）
卡片名「今日待办」，支持 1*2 / 2*2 / 2*4 / 4*4 四种尺寸，一个页面自适应四种排版。
内容：今日待办条数、最多 6 条标题、今日番茄数；1*2 只显示条数与标签。
背景与 App 内「外屏背景」同图，随深浅色切换；宿主强制白底板，故采用同款壁纸而非真透明（已确认不可行）。
刷新链路：App 启动、切回前台、系统深浅色变更、手动切主题、待办增删改，均主动 updateForm 并设置下次刷新时间。
数据源统一：卡片不再自带数据库读取代码，统一走 PREF_NAME 常量与 WidgetSync，避免库名不一致。
中英文：卡片标题、项数、空状态、小卡标签均跟随 App 语言设置（Today / items / No tasks today / Tasks）。
6. 8.x 已知限制
桌面卡片无法加入负一屏（智慧助手·今天）：仅系统服务与已上架元服务可接入，侧载 HAP 无该入口。
卡片透明为「壁纸背景」近似方案；系统未开放卡片宿主背景透明度配置（transparentEnable 被 schema 拒绝）。
卡片在服务卡片列表中的显示名仍为中文；en_US 资源目录未纳入本 HAP 的 locale 打包。
七、8.3.0 → 9.1.4（封装版本）
8.3.0 之后一路都在打磨「写」和「稳」这两件事。
8.4.0 给待办加了备注二级页：新建或编辑待办时，备注不再是挤在一行的输入框，点进去是一整页空白笔记，可以多行随意书写，右下角实时显示字数，支持一键清空，点「完成」内容自动带回编辑弹窗，列表里也会显示备注首行；按需求没有内置任何模板，内容完全由自己写。
9.0.0 是一次整理性版本：作者信息由 tszheoi 改为 Tszheoi Law，该字段仅为元数据，包名与签名均未改变，不影响覆盖安装，也不影响后续上架；同时对新增页面做了一轮排版自检，修掉四处会导致功能不可用的隐患——编辑待办弹窗内容改为可滚动且保存按钮固定底部，弹窗高度限制在屏幕 90% 以内，备注输入框设最小高度避免键盘弹出时被压扁，日程表高度改为自适应避免小屏被底栏遮挡。
9.1.0 修复备注页被待办列表压住的问题：把备注页移到层级最末并赋予最高 zIndex、改成不透明底，同时取消会拦截子组件触摸的事件阻断。
9.1.1 解决备注页「能打开但打不了字」——输入框由按权重分配改为撑满外层容器并加自动聚焦，同时把行内删除按钮从 14px 的小叉放大到 40×40 并加二次确认。
9.1.2 全量自检时查出一个真问题：「待办与专注」虽然标称已加入备份分区，实际并未写入，8.0 至 9.1.1 的备份里一直没有待办与专注数据，现已补齐为六个分区。9.1.3 统一了列表行内的控件规格——勾选框 24×24、播放键 34×34、编辑键 52×34，同底色同圆角；按需求把符号叉改为文字「编辑 / Edit」，删除操作移入编辑弹窗底部并保留确认。
9.1.4 去掉列表行内的番茄钟按键，番茄钟只保留在页面底部；修复暂停后卡死的问题——暂停时只置了暂停标志却漏置运行标志，导致界面永远停在「暂停」且无法继续；同时把计时刷新从 500 毫秒提高到 300 毫秒、点击开始立即重绘圆环，并在时长设置里加入 5 / 15 / 30 分钟快捷选择与自定义输入，番茄钟行也会直接显示当前专注时长。版本号最终定为 9.1.4（versionCode 9001004）。
